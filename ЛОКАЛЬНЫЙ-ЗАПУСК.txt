HackFlow — простой запуск на компьютере без Docker и PostgreSQL

1. Один раз установите Python 3.12 или новее:
   https://www.python.org/downloads/
2. Один раз установите Node.js 22 LTS или новее:
   https://nodejs.org/
3. Распакуйте ZIP ветки hello в обычную папку.
4. На Mac дважды нажмите START-MAC.command.
   Если файл не открывается, в терминале из папки проекта:
   bash START-MAC.command
   На Windows: START-WINDOWS.bat.
   На Linux: python3 scripts/start_local.py
5. Подождите окончания первой установки. Нужен интернет.
6. Сайт откроется: http://localhost:8000

Скрипт сам установит зависимости, соберёт интерфейс и создаст SQLite-базу.

Случайный пароль всех демоаккаунтов напечатан в окне запуска.
Скопируйте пароль из окна; он сохраняется между запусками.
Код команды: HACKFLOW26

Оставьте окно запуска открытым. Для остановки нажмите Ctrl+C.
Для следующего запуска снова откройте START-MAC.command.
Не удаляйте .local-data: здесь база, загруженные файлы и настройки.
.env и существующая PostgreSQL/Docker-база этим режимом не изменяются.

Если порт 8000 занят:
python3 scripts/start_local.py --port 8001
Тогда сайт находится на http://localhost:8001

Старый запуск с Docker: python3 scripts/start_docker.py
