# Дипломы в ветке adele

Ветка создана от main. В ней сохранены функции main и добавлены только сертификаты участия, дипломы 1–3 степени и необходимые открытые результаты с QR-проверкой. Дополнительной папки проекта в репозитории нет.

«Мои дипломы» доступно в боковом меню, в профиле и по /#awards. Сертификаты появляются после публикации результатов; призёры получают дополнительно диплом соответствующей степени. Результаты доступны без входа по /results и /results/ID. PDF содержит имя пользователя, организатора, текстовую подпись и QR. Подпись не является квалифицированной электронной подписью.

После обновления Docker Compose применяет миграцию и оформляет документы для уже опубликованных результатов. Шрифт поставляется с лицензией в backend/hackflow/assets, поэтому скачивание пакетов Debian не требуется.

Цепочка миграций поддерживает базы main, hello и feature/self-registration-levels с известными ревизиями. Для независимой проверки можно использовать отдельный проект Docker Compose: docker compose -p hackflow-adele up --build -d (порт 8000 должен быть свободен; тома создаются отдельно). Существующие тома удалять не нужно.

QR использует PUBLIC_URL из .env. localhost в QR не позволяет проверить документ с другого компьютера или телефона; для этого нужен доступный устройству адрес приложения.


Совместимость существующих баз: ветка распознаёт историю main, adele_awards, a14_team_city и a15_merge_city_awards. Истории сведены в один head adele_compat_heads. Уже существующая таблица документов проверяется и не пересоздаётся; пользователи, команды, городские настройки и документы сохраняются. Добавлены только файлы миграций для совместимости схемы — фронтенд, уровни и административные функции не перенесены. Для обновления выполните git pull origin adele и docker compose up --build -d. Ручной stamp и удаление томов не нужны.
