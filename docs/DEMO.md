# Демонстрация за 7 минут

## 0:00 — проблема и решение

Студенческая команда переключается между чатом, доской, учебными материалами и формой сдачи. HackFlow объединяет основной этап в едином пространстве.

## 0:30 — участник

Вход participant@hackflow.test. Панель показывает сроки, ближайшие события и допуск. Открыть «Моя команда» → код HACKFLOW26 → вступить. Показать кейс, учебный материал и отметку изучения. В расписании открыть реальную внешнюю запись. Демоконсультации без действующей ссылки явно помечены — живые вебинары не имитируются.

## 1:30 — работа команды

Создать задачу, назначить себя, изменить статус селектором или перетаскиванием. Отправить сообщение. В другом браузере под капитаном убедиться, что задача и сообщение видны: это серверные данные, не локальная демонстрация.

## 2:30 — сдача

Капитан заполняет описание, GitHub, демонстрацию и PDF. Прикрепляет ZIP исходников для CodeCheck. Запускает аудит: обязательные поля/дедлайн проверяются, GitHub/README проверяются через GitHub REST API. Недоступный внешний ресурс получает статус «не подтверждено». После подтверждения сдачи время и версия материалов фиксируются, повторная отправка запрещена.

## 3:30 — организатор

Открыть «Управление» → «Проекты», показать отправленный PDF, продукт и репозиторий. В «Участники и жюри» показать импорт CSV, одноразовое приглашение и командные доски. В аналитике Smart Control объясняет предупреждения фактическими данными.

## 4:30 — анонимная проверка

Организатор готовит проверенный обезличенный текст, назначает жюри. Жюри видит случайный код и этот текст, без исходных ссылок и имён. Показать настоящий статус CodeCheck: без второго ZIP нет придуманного процента. Для демонстрации сравнения нужны минимум две команды с отправленными исходниками.

Жюри выставляет баллы. Организатор публикует результат после всех назначенных проверок. Открыть рейтинг и профиль участника: средний рейтинг обновился.

## 5:30 — дополнительные возможности

Показать три темы в настройках, годовой календарь реальных действий, дорожную карту, закрытую переписку организатора и капитана. Peer Review назначается отдельно и не влияет на рейтинг жюри. Апелляция сохраняет причину изменения оценки и пересчитывает рейтинг.

## 6:30 — технологии и ограничения

Flask, PostgreSQL, Flask-SQLAlchemy/Migrate/Login, React/Vite, Tailwind, Lucide, GitHub REST API, pytest. Чат использует REST polling. CodeCheck не исполняет код и не доказывает плагиат; детектор ИИ не заявляется. Успешные серверные проверки — в VALIDATION.md. Для публичной ссылки нужен настроенный VPS; GitHub-репозиторий нужно опубликовать в собственном аккаунте.
