# Русскоязычная подборка учебных материалов

Подборка соответствует форматам §5.3: видеоуроки, презентации, документы, внешние ссылки, вебинары, консультации и задания. Конкретных названий курсов в документе нет; темы выбраны для командной веб-разработки и защиты MVP.

Проверка страниц внешних источников выполнена 15.11.2026. Видео выбраны на авторском канале Александра Ламкова (Friendly Frontend) в Rutube, с русскоязычными названиями, описаниями и таймкодами. Полное воспроизведение роликов в браузере не проверялось; доступность внешних сервисов может измениться.

Всего 16 позиций: 4 видео, 10 документов/внешних материалов, презентация и задание. Вебинары и консультации поддерживаются как форматы с кнопкой подключения; реальные URL и сроки публикует организатор. Выдуманные комнаты не используются.

Внешний контент не копируется и не выдаётся за собственный. Описания карточек — краткие пояснения HackFlow. Презентация и задание созданы в проекте.

Миграция a17_mentors_learning добавляет подборку существующим мероприятиям. catalog_key обеспечивает уникальность позиции внутри хакатона. Повторный seed сохраняет правки организатора, пользовательские материалы и LearningProgress. Распознанные исходные демоматериалы/записи заменяются русскоязычными источниками с сохранением ID. Язык остальных исторических материалов помечается unknown, а не объявляется русским без проверки.

Новые материалы должны быть русскоязычными. API допускает семь форматов и язык ru, проверяет HTTPS для внешних ссылок; у задания ссылка необязательна. Указанный язык — заявление организатора, автоматического анализа аудиодорожки нет.
