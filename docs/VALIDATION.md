# Проверки

Проверки выполнялись в рабочей среде, Python 3.12, Node.js 24, PostgreSQL 17.12. Целевые Docker-образы: Python 3.12, Node.js 22, PostgreSQL 17.

- `npm ci` / `npm run build`: production-сборка Vite проходит.
- `pytest -q` на отдельном **PostgreSQL 17.12**: 21 тест проходит, включая изображения и учебную аналитику.
- Исходные 14 тестов на SQLite: проходят. В исходной версии SQLite использовалась только для тестов; новый локальный режим описан ниже.
- `flask db upgrade` и `flask db check`: три миграции применены на PostgreSQL, расхождений со схемой моделей нет.
- `node frontend/scripts/smoke.mjs` (из frontend): 25 вариантов страниц проходят серверный рендеринг React без ошибок; это не браузерный тест.
- Ограничение одной команды проверяется прямой вставкой дубликата в базу, не только HTTP-ответом.
- Анонимный ответ жюри проверяется на отсутствие названия команды, авторов, исходных ссылок, presentation и team_id.
- CodeCheck проверяется двумя реально загруженными ZIP, а не предзаполненным отчётом.

Сценарии тестов: самостоятельная регистрация без допуска, команда/задача/чат/обучение/сдача, чужая команда, права капитана, запрет удаления после старта, публикация оценки, личный рейтинг, апелляция с пересчётом, диапазоны баллов, дедлайн, неверный PDF, одноразовое приглашение/email, CSV, назначение организатора, сумма критериев, CodeCheck без исходников, сравнение реальных исходников, опасные URL, CSRF, неизменность сдачи, консультации/конфликт жюри, идемпотентные напоминания, Peer Review, одноразовое восстановление пароля.

**Не выполнено:** браузерная проверка визуального результата, реальные SMTP-письма (нет настроенного почтового сервиса), `docker compose up` (Docker daemon отсутствует), публикация Flask на внешнем VPS. Успешные модульные/интеграционные проверки не являются подтверждением этих пунктов.


## Обновление 15 ноября 2026: запуск без Docker

Проверено в Linux, Python 3.12, Node.js, PostgreSQL 16 в отдельном тестовом контейнере:

- Все 36 тестов проходят на SQLite, включая два новых теста launcher.
- Повторный прогон с TEST_DATABASE_URL на выделенной PostgreSQL-базе: 34 теста приложения на PostgreSQL и 2 теста локального launcher на SQLite — все проходят.
- Полная цепочка миграций отдельно успешно применяется на пустой PostgreSQL-базе. Существующие схемы с ревизией a13 не требуют новых миграций.
- Новые тесты используют реальные миграции SQLite, проверяют сохранение данных/секрета/пароля после повторной подготовки, отсутствие дублей демоданных, CHECK размера команды и прав владельца, включённые внешние ключи и изоляцию от Docker/production-переменных.
- Реальный запуск scripts/start_local.py с созданием .venv-local, установкой pip/npm-зависимостей, сборкой React, миграциями, демобазой и единым HTTP-сервером — успешен.
- HTTP-проверка: /api/health сообщает sqlite; HTML, JS и CSS отдаются; вход капитаном с CSRF, чтение команды, создание задачи и отправка сообщения проходят.
- npm run test:render: 26 вариантов страниц проходят серверный рендеринг. npm run build: успешная production-сборка.
- bash -n START-MAC.command: синтаксис оболочки корректен.

Не проверено на настоящем macOS: запуск двойным нажатием в Finder, системные запросы разрешений, автоматическое открытие браузера. Браузерная визуальная проверка не выполнялась. Команда в терминале и HTTP-сценарии проверены в Linux. SQLite-режим предназначен для локального запуска одного процесса; PostgreSQL остаётся основным вариантом серверного развёртывания.

## Обновление оформления

- Основная палитра заменена на графитовую с шалфейными акцентами, новогодняя — на хвойную с тёплыми светлыми деталями. CSS-декларации фиолетовой палитры сохранены без изменений. Идентификаторы тем прежние: сохранённые настройки работают без миграций.
- Общие карточки, формы и элементы управления используют единые скругления, тени и размеры. Сокращены слоганы и повторные подписи; важные инструкции по доступу и отправке сохранены.
- Snowfall: 40 отдельных частиц, SVG-кристаллы и снежная пыль, разные позиции, размеры, отрицательные задержки, скорости и покачивание. На телефоне 24 частицы. Декоративный слой не перехватывает указатель и скрыт от экранных дикторов. При prefers-reduced-motion снег отключается. В новогодних настройках есть сохраняемый переключатель снега.
- 35 проверок серверного рендеринга React проходят, включая отключение снега вне новогодней темы и распределение частиц. Production-сборка Vite успешна.
- Визуальная проверка в браузере и на настоящем macOS не выполнялась.
