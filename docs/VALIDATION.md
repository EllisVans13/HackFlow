- Docker-образ собран с Node 22 и Python 3.12; проверены frontend и стартовый скрипт внутри образа, UID=10001. В данном окружении загрузки pip/npm проходили через временно смонтированный доверенный CA сетевого прокси; проверка TLS не отключалась, production Dockerfile и образ не содержат тестового CA.
- Docker end-to-end с отдельными PostgreSQL 16 и сетью: старт на PORT=10000, health=postgresql, CSRF-вход, восемь мероприятий, загрузка аватара от непривилегированного пользователя, личный PDF и публичная проверка диплома. Пересоздание веб-контейнера с тем же томом сохраняет аватар и пароль, SIGTERM завершает сервер штатно. Отдельно этот же сценарий прошёл с SQLite. Временные контейнеры, сеть и тестовый том удалены.
- Фактическая публикация, биллинг, HTTPS и подключение диска в аккаунте Render пока не проверялись: это следующий пользовательский шаг по docs/RENDER.md. PostgreSQL и файлы из локальной установки не переносятся автоматически.
