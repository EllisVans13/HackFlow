# Проверки актуальной версии main

Сверка выполнена 15.11.2026. Исходная версия кода — `36c9d5e`; в рамках обновления документации также исправлено устаревшее ожидание версии Alembic в `test_local_start.py`: тест теперь проверяет фактическую единственную вершину миграций. Логика приложения и внешний вид не менялись.

Окружение: Python 3.12.14, Node.js 24.22.1, отдельный локальный PostgreSQL 17. Рабочая база Render для тестов не использовалась.

Первый прогон серверных тестов дал 59 успешных и один сбой: тест ожидал прежнюю миграцию `a15_award_certificates`, хотя launcher корректно применил `a16_merge_legacy_histories`. После исправления проверки весь набор запущен повторно. Первоначальная установка npm упёрлась в недоступный стандартный cache окружения; повторный `npm ci --cache /workspace/work/npm-cache` прошёл. Исходники frontend и lockfile не менялись.

Проверки PostgreSQL создают временную отдельную схему для каждого сценария: обновление из base, `55e9b1bb7a5d`, `a14_team_city`, `a14_awards`, `a15_merge_city_awards`, `adele_awards`, `adele_compat_heads`, `a15_award_certificates`. Проверяются повторный upgrade, сохранение существующего пользователя/хеша пароля и старого токена award, создание текущей таблицы award_certificate.

Серверный набор покрывает основной сценарий команды, задачи/чат/обучение/сдачу, изоляцию данных, права капитана, самостоятельную регистрацию в нескольких событиях, передачу капитанства, приглашения, ограничения сотрудников, оценки и апелляции, реальные ZIP для CodeCheck, отсутствие исходников, CSRF, дедлайны, файлы, консультации, напоминания, роли и владельца, уровни, город команд, PDF-дипломы, изображения и локальный запуск.

Предупреждения Alembic о deprecated `get_engine` не привели к сбоям, но требуют отдельного обновления совместимости с будущим Flask-SQLAlchemy.

## Границы проверки

- Визуальная и интерактивная проверка текущей версии в браузере, включая ширину 360–430 px, не проводилась. Серверный рендеринг не подтверждает работу кликов, прокрутки, модальных окон и доступность с телефона.
- Авторизованные сценарии публичного сайта с демоаккаунтами не выполнялись; пароли и данные облачной базы не запрашивались. Наличие всех демоаккаунтов, сохранность загруженных PDF/ZIP/аватаров, worker и постоянного диска не подтверждены.
- Все внешние видеоссылки и образовательные ссылки не проверялись на доступность.
- Реальная отправка SMTP-писем и Telegram-интеграция не проверялись. Telegram-интеграции в текущей реализации нет.
- Docker Compose и реальный запуск миграций в инфраструктуре Render в этой сверке не выполнялись; Docker daemon среды не использовался.
- HTTP health подтверждает соединение с PostgreSQL, но не полноту миграций, наполнение базы и корректность всех функций.

Полное сопоставление обязательных требований и недостающих функций: [CASE_REQUIREMENTS.md](CASE_REQUIREMENTS.md).
