Проблема

Команда теряет время между сервисами

  • Чат, доска задач, материалы и расписание находятся в разных местах
  • Участники пропускают изменения и дедлайны
  • Организатору сложно видеть прогресс и готовность решений

Решение

Весь основной этап в одном пространстве

  • Допуск → команда → кейс → обучение → разработка → сдача
  • Командный чат и Kanban с сохранением данных в PostgreSQL
  • Единое расписание, ссылки на вебинары и внутренние уведомления

Команда

Меньше переключений. Больше результата.

  • Одна команда участника на каждый хакатон — ограничение базы данных
  • Задачи с ответственными, сроками и четырьмя статусами
  • Автоматическая дорожная карта, учебный прогресс и таймер сдачи
  • Капитан сдаёт PDF, GitHub и работающий продукт

Честная проверка

Оценивать решение, сохраняя анонимность

  • Организатор готовит отдельную обезличенную версию материалов
  • Жюри получает случайный код проекта без исходных ссылок и авторов
  • Критерии дают в сумме 100 баллов; итог — среднее оценок экспертов
  • CodeCheck сравнивает токены исходников; сходство не доказывает плагиат

Управление

Понимать, что происходит прямо сейчас

  • Импорт допущенных участников, приглашения жюри и управление контентом
  • Smart Control объясняет предупреждения конкретными фактами
  • Публикация результатов обновляет личные рейтинги участников
  • Апелляции сохраняют историю и причины изменения оценок

Технологии

Полноценный серверный продукт

  • Backend: Python, Flask, SQLAlchemy, Migrate, Login, REST Blueprints
  • Данные: PostgreSQL 17; сессии/CSRF; Redis для лимитов входа
  • Frontend: React, JavaScript, Vite, Tailwind CSS, Lucide
  • Развёртывание: Docker Compose, Gunicorn, Caddy HTTPS, фоновые напоминания
