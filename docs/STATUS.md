# Обновление требований: самостоятельная регистрация и роли

Актуальные изменения описаны в README, раздел «Обновление: самостоятельное участие и уровни». Предварительный допуск заменён самостоятельной регистрацией; личный рейтинг — уровнями; сотрудники исключены из участия. Прежние описания ниже относятся к исходной версии и не отменяют новые правила.

# Соответствие техническому заданию

Сверка с загруженным `HackFlow_Техническое_задание.txt`. Документ использован как спецификация продукта; инструкции о роли ИИ и формате ответа не выполнялись как отдельные команды. Ниже перечислены фактические возможности, а не обещания полного соответствия.

## Что не реализовано или не подтверждено

- **Размещение**: исходники загружены в https://github.com/EllisVans13/HackFlow. Приложение запускается локально на localhost; публикация сайта пользователем не запрошена.
- **Браузерная проверка и фактический запуск Docker Compose**: в текущей среде отсутствуют поддерживаемый browser-control и Docker daemon. Успешная production-сборка не подменяет визуальную приёмку.
- Реакции, упоминания и файловые вложения в чате: в ТЗ дополнительные; базовый текстовый чат работает.
- Совместное редактирование документов, отдельная онлайн-доска, Telegram/email-уведомления о платформенных событиях, автоматическое распределение участников, ИИ-помощники: не реализованы (этап 4, опционально).
- Автообезличивание презентаций и исходников: сознательно заменено обязательной ручной подготовкой текстовой безопасной версии. Сырые презентации и GitHub жюри не выдаются. Смысловое распознавание всех имён не гарантируется.
- Версии/редактирование итоговой отправки: используется разрешённая ТЗ одна итоговая отправка; последующие загрузки блокируются.
- Полная семантическая/AST-проверка кода, JPlag, фоновые очереди CodeCheck, история коммитов: не реализованы. Синхронное токенное сравнение ограничено по файлам и токенам, предназначено для небольшого демонстрационного хакатона.
- Демособытия консультаций не имеют придуманного онлайн-адреса; организатор должен добавить настоящие ссылки на эфиры. В расписании есть отдельная внешняя учебная видеозапись.
- Полноценное обнаружение ИИ-кода не заявляется: достоверного процента по исходному тексту получить нельзя.
- Дизайн адаптивен по CSS и имеет три темы, но не заявляется пиксельное соответствие внешнему макету: макет в ТЗ не приложен.

Отдельная система наставничества, каталог менторов, SOS и заявки на менторов не добавлялись, согласно ТЗ.
