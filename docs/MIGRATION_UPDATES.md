# Обновление базы после смены ветки

`main` распознаёт ранее выпущенные миграции веток `adele` и `feature/self-registration-levels`, включая `adele_compat_heads` и `a15_merge_city_awards`. Общая вершина истории — `a16_merge_legacy_histories`. Для обновления выполните `git pull origin main`, затем `docker compose up --build -d`. Очистка базы, удаление volumes и ручной `db stamp` не требуются. Старые записи таблицы `award` сохраняются; текущие дипломы интерфейса хранятся отдельно в `award_certificate`. Обратный переход на старый код после обновления потребует совместимой истории миграций; объединённая история не поддерживает разрушительный downgrade.



Следующая миграция `a17_mentors_learning` добавляет профиль ментора, выбранного ментора команды и ключи учебной подборки. Она идёт после a16 и не заменяет историю. Создаёт только учебные карточки — не аккаунты с известными паролями. Старые консультации экспертов сохраняются; аккаунты не переводятся в mentor автоматически. Для назначения роли используйте кабинет администратора.


a18_peer_meetings: peer_enabled, отдельный anonymous_file_id, duration_minutes/provider встреч, флаг is_demo. Опубликованные итоги и уже начатые прежние Peer Review остаются в старой схеме; ещё не оцениваемые активные мероприятия переключаются на 80/20. Новые API-мероприятия создаются с peer_enabled=true. После миграций Render/Compose запускает идемпотентный seed-review-demo; он не меняет реальные пароли и восстанавливает только свои демофайлы.
